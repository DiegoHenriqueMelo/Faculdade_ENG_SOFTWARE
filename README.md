### 🎮 Valorant MMR System — *Dev. Software Web I*

Sistema de matchmaking inspirado no Valorant, construído em **arquitetura de microsserviços**: 4 serviços independentes, cada um com seu próprio MongoDB, fila de partidas no Redis, autenticação por JWT, documentação Swagger e stack de observabilidade.

<a href="https://github.com/DiegoHenriqueMelo/valorant-mmr-system" target="_blank"><img src="https://img.shields.io/badge/VER_REPOSITÓRIO-2E9EF7?style=for-the-badge&logo=github&logoColor=white" alt="Ver repositório"></a>

</div>

| Serviço | Porta | Responsabilidade |
|---|---|---|
| 🔐 **Auth Service** | `3001` | Registro, login, JWT e hash de senha com bcrypt |
| 👤 **Player Service** | `3002` | Perfis de jogador: nickname, rank (1–25), agente e região |
| 📊 **MMR Service** | `3003` | Histórico de partidas, cálculo de MMR e leaderboard |
| ⚔️ **Queue Match** | `3004` | Fila no Redis e formação de times 5v5 equilibrados por MMR |

**Stack:** Node 20 • TypeScript • Express 5 • MongoDB 7 • Redis 7 • Docker Compose • Swagger/OpenAPI 3.0 • Prometheus • Grafana • Winston

**Testes de carga:** k6 • Artillery • JMeter • Locust

## 🚀 Quick Start

<details>
<summary><b>🎮 Valorant MMR System (Dev. Software Web I)</b></summary>

```bash
cd "3º ano/Desenvolvimento de Software para Web I/Exercicios/valorant-mmr-system"

# Configure as variáveis a partir do exemplo
cp .env-example .env

# Sobe o stack completo: 4 serviços + 4 MongoDB + Redis + Prometheus + Grafana
docker compose up -d
docker compose ps

# Popular dados de teste (opcional)
docker compose exec player-service npm run seed

# 📚 Swagger de cada serviço: http://localhost:3001/api-docs (3002, 3003, 3004)
# 📈 Grafana: http://localhost:3000
```

## 🚀 Quick Start

<details>
<summary><b>🎨 Projeto Postly (Empreendedorismo II)</b></summary>

```bash
# Navegue até o diretório
cd "Empreendedorismo II/Exercicios/Postly"

# Instale as dependências
npm install

# Execute o projeto
npm run dev

# 🌐 Acesse: http://localhost:5173
```

</details>

<details>
<summary><b>🔧 Sistema PCD (Paradigmas II)</b></summary>

```bash
# 🗃️ Backend
cd "UCE - Paradigmas da Programação II/Exercicios/app/backend"
npm install
npm run dev

# 🎨 Frontend (novo terminal)
cd "UCE - Paradigmas da Programação II/Exercicios/app/frontend"
npm install
npm run dev

# 🌐 Backend: http://localhost:3000
# 🌐 Frontend: http://localhost:5173
```

</details>
